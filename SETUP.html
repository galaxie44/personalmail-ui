Configurer Google (gratuit, ~2 min)

L’interface tourne dans ton navigateur (pages GitHub, 0 €). Google exige un client OAuth de type Application Web.

  1. Ouvre Google Cloud → Identifiants (projet camera-orthez ou le tien).
  2. Active l’API Gmail si besoin : Gmail API.
  3. Créer des identifiants → ID client OAuth → type Application Web.
  4. Origines JavaScript autorisées — ajoute :
    • https://galaxie44.github.io
    • http://127.0.0.1:5500 (test local optionnel)
  5. Copie le Client ID dans config.js (clientId: "….apps.googleusercontent.com").
  6. Écran de consentement OAuth : ajoute ton compte Google comme utilisateur de test si l’app est en mode « Testing ».
Ne mets jamais le client_secret dans cette interface. Un secret exposé → régénère-le dans la console Google.
