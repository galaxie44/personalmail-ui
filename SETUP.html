Configurer Google (gratuit, ~2 min)

Si tu vois 401 invalid_client / no registered origin : tu utilises encore un client Desktop. Il faut un client Application Web avec l’origine ci‑dessous.

  1. Ouvre Google Cloud → Identifiants (projet camera-orthez ou le tien).
  2. Active l’API Gmail si besoin : Gmail API.
  3. Créer des identifiants → ID client OAuth → type Application Web (pas « Application de bureau »).
  4. Nom : PersonalMail UI.
  5. Origines JavaScript autorisées — ajoute exactement :
    • https://galaxie44.github.io
    (pas de chemin /personalmail-ui, uniquement le domaine.)
  6. URI de redirection : laisse vide (pas besoin pour GIS).
  7. Créer → copie le Client ID (…apps.googleusercontent.com).
  8. Colle-le dans config.js du repo personalmail-ui, ou envoie-le-moi et je pousse la mise à jour.
  9. Écran de consentement : si mode « Testing », ajoute edouard.clemenceau.pro@gmail.com comme utilisateur de test.
Ne mets jamais le client_secret dans cette interface. Le Client ID seul suffit.
