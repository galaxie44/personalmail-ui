# PersonalMail — interface web gratuite

Page statique hébergée sur **GitHub Pages** (0 €, sans carte bancaire).  
Tu te connectes avec Google ; le tri passe **directement** par l’API Gmail dans ton navigateur.

## URL

https://galaxie44.github.io/personalmail-ui/

## Setup OAuth (une fois)

Voir [SETUP.html](SETUP.html) : créer un client OAuth **Application Web** et coller le Client ID dans `config.js`.

## Fonctions

- Liste de la boîte
- Tri manuel / « Trier la boîte »
- Résumé envoyé à toi-même
- Lien vers les jobs cloud GitHub Actions
